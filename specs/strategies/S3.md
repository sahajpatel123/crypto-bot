# S3 range mean reversion (SPEC, unimplemented — Worker 1, Q-002)

Status: SPEC (no code). D-010 correction: this spec implements the
directive's S3 hypothesis (range mean reversion), replacing the Q-001
funding-tilt draft. Simulation only; not a validated trading system.

## Hypothesis

When price is contained in a measured range and momentum stalls at an edge,
fade the edge toward the range mid. Long/short evaluated separately.

## Proposed frozen parameters (v0.1.0, to be pinned at implementation)

| Name | Value | Meaning |
|---|---|---|
| `RANGE_N` | 120 | range window: bars `t-120..t-1` |
| `STALL_M` | 30 | stall lookback in bars |
| `STALL_MAX_BPS` | 3.0 | max \|30-bar return\| (stall deadband) |
| `EDGE_TOL_BPS` | 4.0 | max distance of `close[t]` inside the edge |
| `SPREAD_MAX_BPS` | 2.0 | tighter than S1/S2 (fade needs quiet book) |
| `ENTRY_TOL_BPS` | 2.0 | entry-bound width |
| `ENTRY_EXPIRY_S` | 15 | entry expiry |
| `HOLDING_LIMIT_S` | 120 | time stop |

Exit rule (proposed): `S3_EXIT_V1:take_mid=1.0,stop_r=1.0` — target the
range mid (`(H+L)/2`), stop `1.0R` beyond entry where `R` = distance to
invalidation. Costs: S1/S2 frozen preset, `conservative-simulation`.

## LONG rules (SHORT mirrors)

1. Range: `H = max(high[t-120..t-1])`, `L = min(low[t-120..t-1])`;
   range width `(H−L)/L·10⁴ >= 15.0` bps (reject dust ranges).
2. Position: `close[t]` within `EDGE_TOL_BPS` above `L`
   (`(close[t]−L)/L·10⁴ <= 4.0`, and `close[t] >= L`).
3. Stall: `|(close[t]/close[t-30] − 1)·10⁴| <= 3.0` bps.
4. Spread: `spread_bps[t] <= 2.0`.
5. Entry: `entry_low = close[t]·(1−2bps)`, `entry_high = close[t]`;
   `invalidation = L·(1−2bps)` (below entry since `close[t] >= L`).

Reject ladder: `history` (`t >= 120`), `gap`, `spread`, `range-width`,
`position`, `stall`, `bounds`. Regime `range-long` / `range-short` /
`no-setup`. No confirmation arms in v0.1.0 (single arm `S3` proposed;
volume/flow confirmation deferred to a later preregistration).
