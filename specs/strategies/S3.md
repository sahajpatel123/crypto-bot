# S3 range/VWAP mean reversion — exact rules v0.1.0 (Worker 1, Q-004)

Status: BASELINE (simulation only; not a validated trading system).
Directive Sec 5 hypothesis: fade measured range edges toward value when
momentum stalls. Replaces the Q-002 unimplemented S3 SPEC.
Contract: v0.2.0 (Intent schema unchanged). Strategy-side builders reuse
manager-owned `cryptobot.coordination`. All replay inputs are synthetic
and labelled (`source: "synthetic"`).

## 1. Bar schema and causality

Same 1-second bar schema as S1/S2. Evaluate at bar index `t`;
`evidence_ts_utc` = `bars[t].ts_utc`. Range, VWAP, touches and stall are
measured over bars ending at `t-1` or `t` as stated below — every window
ends at `t` or earlier. Minimum history `t >= 120` (shared replay warmup).
Smaller `t` yields no evaluation (`history=fail`).

## 3. Arms (bounded alternatives for EXP-003)

- `S3` — edge fade: range + position + stall + VWAP side + spread.
- `S3-R` — plus regime filter: width `<= 120` bps AND `>= 2` edge touches
  in the last 60 bars.
- `S3-C` — plus cost cover: entry-to-mid distance `>= 26.0` bps (covers
  one estimated round trip; a filter, not a profit claim).

All arms share version `0.1.0`. No volume/flow arms for S3.

## 4. Per-side rules (long and short evaluated separately)

### 4.1 LONG fade of the low edge (all must hold)

1. Range: `H = max(high[t-120..t-1])`, `L = min(low[t-120..t-1])`;
   `width = (H−L)/L·10⁴ >= 15.0` bps.
2. Regime (S3-R only, `na` on other arms): `width <= 120.0` AND touches
   `>= 2`, where a touch is a bar `i` in `t-60..t-1` with
   `(low[i]−L)/L·10⁴ <= 4.0`.
3. Position: `L < close[t]` (strict) and `(close[t]−L)/L·10⁴ <= 4.0`.
4. Stall: `|(close[t]/close[t-30] − 1)·10⁴| <= 3.0` bps.
5. VWAP side: `close[t] < vwap` (strict), `vwap` over `t-60..t-1`
   (typical-price weighted; zero total volume fails the gate).
6. Cost cover (S3-C only, `na` on other arms):
   `(mid − close[t])/close[t]·10⁴ >= 26.0`, `mid = (H+L)/2`.
7. Spread: `spread_bps[t] <= 2.0`.

No-trade conditions: range narrower than 15 bps (dust), no stall
(trending tape — momentum above the deadband), mid-range prints (not at
an edge), close at/above VWAP (no value), spread above 2 bps, any gap
in `t-120..t`.

### 4.2 SHORT fade of the high edge (mirror)

1. Same `H/L/width >= 15.0`.
2. S3-R: `width <= 120.0` AND `>= 2` touches
   (`(H−high[i])/H·10⁴ <= 4.0` over `t-60..t-1`).
3. `close[t] < H` (strict) and `(H−close[t])/H·10⁴ <= 4.0`.
4. Same stall deadband.
5. `close[t] > vwap` (strict).
6. S3-C: `(close[t] − mid)/close[t]·10⁴ >= 26.0`.
7. Same spread gate.

### 4.3 Reject checks (in order, every outcome recorded)

`history`, `gap` (window `t-120..t`; halt/degraded; never emit on gaps),
`spread`, `range`, `regime`, `position`, `stall`, `vwap`, `cost`,
`bounds`. All gates evaluated independently; fire requires every
applicable gate to pass.

Regime labels: `range-long` / `range-short` on fire, else `no-setup`.
Trigger strings: `range(120)+stall(30)+vwap(60)` plus `+regime` /
`+costcover` on filtering arms; `no-fire` otherwise.

Signal persistence: S3 signals on EVERY bar while the edge + stall +
value conditions hold (resting at the edge re-confirms each bar); it has
no fresh-touch novelty clause by design. Single exposure is owned
downstream (coordinator dedup, risk one-position).

## 5. Intent construction on fire

- `strategy` = arm id; `version = "0.1.0"`; side = evaluated side.
- LONG: `entry_low = close[t]·(1−2bps)`, `entry_high = close[t]`,
  `invalidation = L·(1−2bps)`. Ordering proof: position gives
  `close[t] > L`, so `entry_low = close[t]·(1−2bps) > L·(1−2bps) =
  invalidation` strictly.
- SHORT: `entry_high = close[t]`, `entry_low = close[t]·(1−2bps)`,
  `invalidation = H·(1+2bps)` (mirror proof).
- `entry_expiry_utc = evidence + 15s`; `holding_limit_s = 120`;
  `exit_rule`, `forecast_cost` from §2; `data_quality = clean`
  (`no-gaps-N=120`); `evidence_ref` = deterministic record id
  (`{strategy}:{version}:{instrument}:{side}:{iso}`).
- The paired `DecisionRecord` carries regime, one `FeatureEvidence` per
  evaluated feature, the trigger clause, all reject outcomes, and the
  data-quality state. No confidence percentages.
