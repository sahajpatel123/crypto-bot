No microstructure is fabricated: missing depth/flow stays missing and every
rejection carries the relayed `depth:`/`flow:` reason.

## 1. Inputs (runtime boundary)

S5 consumes `strategies/runtime.py::MarketView` only:

- `bars`: bounded causal 1 s bars, oldest→newest, newest closes `<= now_utc`.
  Same bar schema as S1.md section 1. Minimum window: 31 bars.
- `depth`: `DepthView | None` — synced-book features from the E-007 bridge
  (`best_bid/ask`, top sizes, `spread_bps`, per-side notional within
  `levels`, top-K `imbalance` in `[-1, 1]`, `ts_utc`). `None` whenever the
  book is unsynced, with the E-007 reason in `quality_reason`.
- `flow`: `FlowView | None` — signed trade aggregates over a causal window
  (`buy/sell_notional`, `buy/sell_count`, `vwap`, `trade_count`,
  `window_start/end_utc`). `None` whenever the window is incomplete, with
  the E-007 reason in `quality_reason`.
- `quality_reason`: `;`-joined data reasons, e.g.
  `"depth:unsynced-no-snapshot;flow:empty-window"`. Absent side → fallback
  `depth:unavailable` / `flow:unavailable` (never invented quantities).

## 2. Evaluation point and causality

Evaluate at the newest bar `t = len(bars) - 1`; `evidence_ts_utc` = its
close time. Depth/flow snapshots must satisfy
`evidence_ts_utc - SYNC_MAX_AGE_S <= snapshot_ts <= evidence_ts_utc`
(snapshots newer than evidence are peeking and rejected; older ones stale).
Reference/invalidation windows EXCLUDE bar `t`; bar `t`'s own fields are
causal at its close.

## 3. Frozen parameters v0.1.0

Recorded here BEFORE any evaluation outcome was observed (Q-005 evidence).

| Name | Value | Meaning |
|---|---|---|
| `IMB_MIN` | 0.20 | min \|top-K book imbalance\| |
| `FLOW_MIN` | 0.58 | min directional buy fraction of flow notional |
| `FLOW_MIN_TRADES` | 10 | min `trade_count` in the flow window |
| `SYNC_MAX_AGE_S` | 2 | max depth/flow snapshot age vs evidence |
| `SPREAD_MAX_BPS` | 3.0 | reject if trigger-bar `spread_bps` above |
| `DEPTH_SPREAD_MAX_BPS` | 5.0 | reject if synced-book spread above |
| `INVAL_M` | 30 | swing window: bars `t-30..t-1` |
| `INVAL_BUF_BPS` | 1.0 | invalidation buffer beyond the extreme |
| `ENTRY_TOL_BPS` | 2.0 | entry-bound width from trigger close |
| `ENTRY_EXPIRY_S` | 15 | `entry_expiry_utc = evidence + 15s` |
| `HOLDING_LIMIT_S` | 120 | inside contract range 30–300 |
| `TAKE_R` | 1.5 | target distance in R multiples |

Exit policy: stop at invalidation, target `close[t] ± 1.5R` with
`R = |close[t] − inval|`, time exit `evidence + HOLDING_LIMIT_S`, encoded
via `encode_exit_rule` with policy id `S5:stop+target+time` (same grammar
as S1/S2/S4; S3 targets range mid instead).

Forecast cost (per-side estimates, labelled `conservative-simulation`,
every leg non-zero):
`fee_bps=5.0, spread_bps=5.0, slippage_bps=5.0, funding_bps=1.0`.
Cost checks: the forecast is attached to every S5 intent; the bar-spread
and book-spread gates above are the cost-adjacent rejects.

## 4. Arms

- `S5` — the single baseline arm (no ablations preregistered).

## 5. Per-side rules (long and short evaluated separately)

`buy_frac = buy_notional / (buy_notional + sell_notional)`; a zero-total
window yields `0.5` (neutral, never fires).

### 5.1 LONG trigger (all must hold)

1. `imbalance >= +IMB_MIN` (bid pressure) AND `buy_frac >= FLOW_MIN`
   (buy aggression agrees). Both legs required; disagreement = no fire.

### 5.2 SHORT trigger (mirror)

2. `imbalance <= -IMB_MIN` AND `buy_frac <= 1 - FLOW_MIN`.

### 5.3 Reject checks (evaluated in order, every outcome recorded)

`quality` (HALT → `quality:halt`), `depth` (None → relayed `depth:*`
reason), `flow` (None → relayed `flow:*` reason), `sync` (snapshot newer
than evidence or older than `SYNC_MAX_AGE_S` → `sync:depth-stale` /
`sync:flow-stale` / `sync:depth-from-future` / `sync:flow-from-future`),
`history` (window shorter than 31 → `insufficient-history`),
`flowcount` (`trade_count < FLOW_MIN_TRADES`), `spread` (bar or book
spread above max), `signal` (imbalance/flow disagree or below threshold).
Relayed E-007 reasons keep their shape end to end
(`StrategyOutcome.reject_reason` carries them verbatim).

## 6. Intent construction on fire

`entry = close[t] ± ENTRY_TOL_BPS` (long: `[close, close·(1+tol)]`, short
mirrored), `entry_expiry_utc = evidence + ENTRY_EXPIRY_S`. Invalidation:
long `inval = min(low[t-30..t-1])·(1 − buf)`, short mirrored about the
max high. `holding_limit_s = 120`. Feature evidence records the imbalance
value + threshold, the flow buy fraction + threshold, and both spreads.
