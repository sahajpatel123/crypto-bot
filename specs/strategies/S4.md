# S4 failed-breakout reversal (SPEC, unimplemented — Worker 1, Q-002)

Status: SPEC (no code). D-010 correction: this spec implements the
directive's S4 hypothesis (failed-breakout reversal), replacing the Q-001
ATR-breakout draft. Simulation only; not a validated trading system.

## Hypothesis

A breakout pierce that fails to hold and is reclaimed within a few bars
traps momentum chasers; enter the reversal toward the range interior.
Long/short evaluated separately (LONG fades a failed downside breakdown).

## Proposed frozen parameters (v0.1.0, to be pinned at implementation)

| Name | Value | Meaning |
|---|---|---|
| `REF_N` | 120 | reference window: bars `t-120..t-1` |
| `PIERCE_MAX_BPS` | 6.0 | max pierce beyond the level (else true breakout) |
| `RECLAIM_K` | 5 | reclaim must occur within 5 bars of the pierce bar |
| `MOM_M` | 10 | reversal momentum lookback |
| `MOM_MIN_BPS` | 4.0 | min 10-bar reversal return toward the interior |
| `SPREAD_MAX_BPS` | 3.0 | reject if above |
| `ENTRY_TOL_BPS` | 2.0 | entry-bound width |
| `ENTRY_EXPIRY_S` | 15 | entry expiry |
| `HOLDING_LIMIT_S` | 120 | time stop |

Exit rule (proposed): `S4_EXIT_V1:take_r=1.5,stop_r=1.0`. Costs: S1/S2
frozen preset, `conservative-simulation`.

## SHORT rules — fade a failed upside breakout (LONG mirrors)

1. Level: `H = max(high[t-120..t-1])`.
2. Pierce: some bar `p` in `t-6..t-1` with `high[p] > H` and
   `(max(high[t-6..t-1])−H)/H·10⁴ <= 6.0` (shallow pierce only).
3. Reclaim: `close[t] < H` and `close[t] < min(close[t-5..t-1])`
   (back inside, breaking the micro-lows).
4. Reversal momentum: `(close[t]/close[t-10] − 1)·10⁴ <= −4.0` bps.
5. Spread: `spread_bps[t] <= 3.0`.
6. Entry: `entry_high = close[t]`, `entry_low = close[t]·(1−2bps)`;
   `invalidation = max(high[t-6..t])·(1+2bps)` (above entry since the
   pierce high exceeds `close[t]`).

LONG mirrors with `L = min(low[t-120..t-1])`, pierce below, reclaim above.
Reject ladder: `history` (`t >= 120`), `gap`, `spread`, `level`,
`pierce`, `reclaim`, `momentum`, `bounds`. Regime `failed-breakout-short` /
`failed-breakout-long` / `no-setup`. Single arm `S4` in v0.1.0.
