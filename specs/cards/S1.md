# Strategy card: S1 breakout-momentum v0.1.0 (Worker 1, Q-007)

Normative rules: `specs/strategies/S1.md`. This card is the backtest-facing
summary (B6): every field below is exact. Baseline arm for comparisons: `S1`.

## Inputs

- Causal 1 s bars (`open/high/low/close`, `volume`, `trades`, `buy_frac`,
  `spread_bps`), oldest→newest, newest closes ≤ now. Missing windows are
  explicit `None` slots (never compressed).
- No depth or flow views consumed.

## Setup

- Minimum history `t ≥ 120`. Reference windows exclude bar `t`; bar `t`'s
  own fields are causal at its close.
- Frozen params: `BREAKOUT_N=120`, `MOM_M=30`, `MOM_MIN_BPS=5.0`,
  `SPREAD_MAX_BPS=3.0`, `ENTRY_TOL_BPS=2.0`, `ENTRY_EXPIRY_S=15`,
  `HOLDING_LIMIT_S=120`, `INVAL_M=30`, `TAKE_R=1.5`, `HALT_GAP=5`.
  (`VOL_V/VOL_Z_MIN/FLOW_F/FLOW_MIN` belong to the `S1-V`/`S1-F` arms,
  not the baseline.)

## Trigger (all must hold)

- LONG: `close[t] > max(high[t-120..t-1])` AND 30-bar return
  `(close[t]/close[t-30]−1) ≥ +5 bps`.
- SHORT: mirror (`close[t] < min(low[…])`, return `≤ −5 bps`).

## Rejects (evaluated in order)

`history` (`t<120` or trigger bar missing), `gap` (any `None`/disorder in
the 120-bar window; `>5` consecutive or disorder → halt quality),
`spread` (`spread_bps[t] > 3.0`), `breakout`, `momentum`, `confirm`
(`na` on the base arm).

## Entry bounds / expiry

- LONG: `[close[t], close[t]·(1+2bps)]`; SHORT mirrored.
- `entry_expiry_utc = evidence + 15 s`. Backtest fill: first touch of the
  box after the signal bar (taker cross of the touched bound).

## Invalidation

- LONG: `min(low[t-30..t-1])` exactly (no buffer); SHORT mirrored about
  `max(high[t-30..t-1])`.
- The invalidation price doubles as the protective stop.

## Stop / target / time

- Stop at invalidation; target `close[t] ± 1.5R`, `R = |close[t] − inval|`;
  time exit `evidence + 120 s`; exits reduce-only.
- Wire: `encode_exit_rule` policy id `S1:stop+target+time`.

## Holding range

- `HOLDING_LIMIT_S = 120` (inside the contract 30–300 s range).

## Units

- One intent per side per bar at most; quantity is NOT set here — risk
  `plan_size` sizes from the reservation (USDT-perp, base qty quantized to
  venue step). Forecast cost attached per intent (frozen
  `conservative-simulation` preset, all legs non-zero).
