# Strategy card: S5 microstructure baseline v0.1.0 (Worker 1, Q-007)

Normative rules: `specs/strategies/S5.md`. Backtest summary (B6); every
field exact. Baseline arm for comparisons: `S5` (single arm, no ablations).

## Inputs

- Causal 1 s bars (minimum 31) PLUS synchronized microstructure views on
  the runtime `MarketView`: `depth` (synced-book features) and `flow`
  (signed trade aggregates). Either view `None` ⇒ ineligible with the
  precise relayed reason (see B4 contract below); nothing is estimated.
- No other inputs. In particular S5 NEVER derives imbalance, spread, or
  pressure from estimated/modelled BBO: modelled quotes (including the
  `research-spread-profile` assumption) may drive bar construction for
  S1–S4, but S5 treats a window without synchronized observed views as
  ineligible, full stop.

## Setup

- Evaluate at the newest present bar `t`; `evidence_ts_utc` = its close.
  Depth/flow snapshots must satisfy
  `evidence − 2 s ≤ snapshot_ts ≤ evidence` (newer = peeking, older =
  stale; both rejected, never interpolated).
- Frozen params: `IMB_MIN=0.20`, `FLOW_MIN=0.58`, `FLOW_MIN_TRADES=10`,
  `SYNC_MAX_AGE_S=2`, `SPREAD_MAX_BPS=3.0`, `DEPTH_SPREAD_MAX_BPS=5.0`,
  `INVAL_M=30`, `INVAL_BUF_BPS=1.0`, `ENTRY_TOL_BPS=2.0`,
  `ENTRY_EXPIRY_S=15`, `HOLDING_LIMIT_S=120`, `TAKE_R=1.5`.

## Trigger (all must hold)

- LONG: top-K book imbalance `≥ +0.20` AND flow buy fraction
  `buy/(buy+sell) ≥ 0.58` (both legs required; disagreement = no fire).
- SHORT: imbalance `≤ −0.20` AND buy fraction `≤ 0.42`.
- Zero-total flow window ⇒ neutral `0.5`, never fires.

## Rejects (in order)

`quality` (HALT), `depth` (relayed `depth:*`), `flow` (relayed `flow:*`),
`sync` (stale/from-future snapshots), `history` (`<31` bars), `gap`,
`flowcount` (`<10` trades), `spread` (bar or book), `signal`, `bounds`.

## Entry bounds / expiry

- LONG: `[close[t], close[t]·(1+2bps)]`; SHORT mirrored.
- `entry_expiry_utc = evidence + 15 s`; taker-cross fill on first box
  touch after the signal bar.

## Invalidation

- LONG: `min(low[t-30..t-1])·(1−1bp)`; SHORT mirrored about the max high.
  Stop = invalidation.

## Stop / target / time

- Stop at invalidation; target `close[t] ± 1.5R`, `R = |close[t] − inval|`;
  time exit `evidence + 120 s`; reduce-only; policy id
  `S5:stop+target+time` via `encode_exit_rule`.

## Holding range

- `HOLDING_LIMIT_S = 120` (contract range 30–300 s).

## Units

- One intent per side per evaluation at most; sizing owned by risk
  `plan_size` (USDT-perp, venue-quantized). Frozen
  `conservative-simulation` forecast cost attached per intent.

## B4 consumption contract (for the manager's Session wiring)

E-008's `market_data/views.py` supplies `BookView`/`FlowView2` via
`DepthStore.book_flow_for()`; the manager maps them onto
`MarketView.depth`/`flow` (`strategies/runtime.py`
`DepthView`/`FlowView`). Exact mapping S5 requires:

- Present book ⇒ `DepthView(best_bid/best_ask` = `bids[0]`/`asks[0]`
  prices, `bid/ask_qty` = top sizes, `spread_bps` = `BookView.spread_bps`,
  notionals over the observed `levels`, `imbalance` =
  `BookView.imbalance_top1`, `ts_utc` = `ts_ms`). Absent book ⇒
  `depth=None` with the `book:*` reason verbatim (`book:never-synced`,
  `book:resync-in-flight`, `book:empty-book`).
- `quality == "stale"` (sync age beyond tolerance) or
  `imbalance_top1 is None` (empty top) ⇒ treat as absent (`None` +
  `book:stale-book` / `book:empty-book`); S5 never evaluates on stale or
  unmeasured books.
- Present flow ⇒ `FlowView` from `FlowView2` notionals/counts/VWAP with
  `window_end_utc` = `window_end_ms`; absent ⇒ `flow=None` with the
  `flow:*` reason verbatim (`flow:no-trades-yet`,
  `flow:window-incomplete`, gap reasons). A `chain-resync` window is
  usable (re-anchored); only a missing aggregate is ineligible.
- NEVER substitute modelled/estimated BBO, spread, or imbalance into
  these views: S5 cannot distinguish estimates from observations, so any
  estimation must surface as `None` + reason instead.
- `quality_reason` carries the `;`-joined `book:`/`depth:`/`flow:`
  tokens; S5 relays the first matching token verbatim into
  `reject_reason` (`depth:` and `book:` both accepted), so ineligible
  windows stay precisely attributable end to end.
